Unity Import

Notifications

Show desktop notifications when downloads complete or fail.

Downloads Monitor

When enabled, BB's LibMan watches your downloads folder and shows a notification when a 3D asset or archive finishes downloading.

Malware Scanning

Scans imported .unitypackage files (and .zip/.rar/.7z archives that contain them) with the vrchat-scanner CLI in the background after import.

Also scan assets already in your library that haven't been checked yet — one at a time, only after the computer has been idle for a few minutes, so it never competes with what you're doing.

Booth Library Manager

When enabled, items from your local Booth Library Manager database are shown in the library alongside your own assets.

URL Schemes

Register BB's LibMan as the default handler for custom URL protocols. Other apps (like Booth Library Manager) can then launch and interact with this app via these links.
