# Project instructions

- Unless the user specifies otherwise, always respond in ASD-STE100 Simplified Technical English.
- When the user says "Wrap it up", ask which release type to use: Major, Minor, or Patch. Do not start the release until the user selects one.
- After the user selects the release type, increase the respective project version, update the release notes, validate and build the project, create the GitHub release, upload the required build files and release metadata, and complete all other steps needed for a working new release.
