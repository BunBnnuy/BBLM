Library

Title Translations

Show English translations of Japanese item titles. MyMemory receives only the title. Translations are saved with each item. Existing saved items are processed one at a time. Original titles are kept.

Free use is limited to 5,000 characters per day. Titles over 500 UTF-8 bytes are skipped. Save settings to apply. Turn this off to show original titles and stop new requests.

Hidden Assets

Assets you've hidden from the library. Click Unhide to restore them.

No hidden assets.

Public Showcase

Create a public catalog snapshot with card details, listed filenames, and resized JPEG previews. Adult-marked and hidden assets are excluded. Original asset files and local paths are never included.

Unity Import

Import the companion package into any Unity project once, and it will show up here automatically whenever that project is open. Then right-click an archive asset and choose "Import to Unity" to select files and a target project.

Import BBLM_Importer.unitypackage into your project once.
None detected. Open a project with the companion package installed.

Booth Library Manager

When enabled, items from your local Booth Library Manager database are shown in the library alongside your own assets.

URL Schemes

Register BB's LibMan as the default handler for custom URL protocols. Other apps can then launch and interact with this app through these links.

Notifications

Show desktop notifications when downloads complete or fail.

Downloads Monitor

When enabled, BB's LibMan watches your downloads folder and shows a notification when a 3D asset or archive finishes downloading.

Malware Scanning

Scans imported .unitypackage files and archives that contain them with the vrchat-scanner CLI in the background after import.

Also scan assets already in your library that have not been checked. Scans run one at a time after the computer has been idle for a few minutes.
